v0.4.0

LatestNovember 8, 2026

WinKillSwitch 0.4

Everything planned for this round, finished and tested together. If you are coming from v0.1, here is what you get.

Clean up

  • Memory cleaner (v0.2): a live memory ring and one button. It trims what apps are not using, clears the standby cache and shows exactly what it freed.
  • Disk cleaner (v0.3): analyze temporary files, caches and leftovers, review the list, clean in one step. It never follows links, keeps files from the last week and skips anything in use.
  • Why is my PC slow? (v0.3.7): five seconds of watching, then a plain answer with the fix one click away.

Understand

  • About this process (v0.3.1): what it is, who signed it, and why access may be denied.
  • More columns (v0.3.2): type, status, publisher, command line, GPU, GPU engine and now network (v0.3.11). Right click the header to choose.
  • Find by window (v0.3.3), quick palette with Ctrl+K or Ctrl+Shift+K from anywhere (v0.3.4), process tree (v0.3.5).
  • Who is using this file? (v0.3.6): drop a file to see which apps hold it open.
  • Starts with Windows (v0.3.10): every autostart entry in one read-only list, with unusual ones flagged.

Control

  • New process alerts (v0.3.8): hear about programs you watch, or anything started from Downloads or Temp.
  • Limits (v0.3.9): cap a program's processor and memory use; it keeps running.
  • Rule packs (v0.3.12): Gaming mode, Bloat blocker and Quiet laptop in one switch, plus import and export.

New in this release

  • On narrow windows the process table hides its least important columns instead of spilling past the edge, and the toolbar no longer overlaps.

Still to come

Ending processes, the PauseSwitch system changes, and signed releases. See the roadmap.

v0.3.12

November 8, 2026

Rule packs

Ready made setups you can switch on in one press, and your own rules as a file you can share.

  • Settings > Rule packs has three profiles:
    • Gaming mode: OneDrive, Dropbox, Google Drive, Teams, Slack and Spotify capped so your game gets the processor.
    • Bloat blocker: alerts when updaters or anything from Downloads or Temp start, with background updaters capped.
    • Quiet laptop: browsers and chat apps capped for quieter fans and longer battery life.
  • Turning a profile off removes exactly the rules it added and keeps any you changed since.
  • Export my rules saves your limits and alerts as JSON. Import a pack merges one in after checking it, so a bad file never half applies. The profiles are in packs/ as examples.

Safety

  • Limits now double check every process before touching it: the program on disk must match the rule's name, and nothing in the Windows folder is ever limited, even if a process id was reused.

v0.3.10

November 8, 2026

Starts with Windows

See everything that launches itself, wherever it hides.

  • PauseSwitch > Starts with Windows lists the Run and RunOnce registry keys (yours, the machine's and 32-bit), policy Run keys, both Startup folders, scheduled tasks that run at sign in or boot, and automatic services.
  • Each entry shows its publisher, its command and whether Task Manager has disabled it. Show file opens its folder.
  • Microsoft's own entries are hidden by default (one switch shows them), so the list is what you installed.
  • A changed Winlogon shell or userinit, or active AppInit DLLs, are flagged at the top as unusual: classic places for malware to hide.
  • The view only reads. It never changes anything.

Fixes

  • Some programs' publisher names could carry stray text from the next version field.

v0.3.9

November 8, 2026

CPU and memory limits

Limits

Keep a heavy program from taking over your PC, without closing it.

  • Open a process's Details and choose Set limits.
  • Processor: 50%, 25% or 10% of your processor for the whole program, all its processes together. It runs slower, never breaks.
  • Memory: 4 GB, 2 GB, 1 GB or 512 MB of RAM per process. Windows moves the rest to disk instead of refusing memory, so the program keeps running.
  • Limits are remembered by program name and come back every time it starts. Settings > Limits lists them; remove one and the program is free immediately.
  • Windows' own processes cannot be limited.

Tested on a real machine: a busy process went from 8.3% to 2.4% of the processor under a 2% cap, and a process holding 481 MB dropped to 127 MB under a 128 MB ceiling while it kept running.

v0.3.7

November 8, 2026

Why is my PC slow?

One button, one plain answer.

  • Press Why is my PC slow? on the Clean tab (or find it in the quick palette, Ctrl+K).
  • WinKillSwitch watches your PC for about five seconds, then checks the processor, memory, disk space, disk activity, graphics and uptime, worst first.
  • When a process is behind it, you see its name. The numbers are averaged, so a one-second spike is not blamed.
  • Each problem comes with its fix: Show it, Clean memory or Analyze disk.

Fixes

  • The Disk column could show an impossible rate for a process the first time it was sampled. It now starts at zero.
  • The system drive labels no longer run together on a narrow window.

Who is using this file?

"The action can't be completed because the file is open in another program." Now you can find out which program.

  • Drop a file or folder anywhere on the WinKillSwitch window, or open the quick palette and choose Who is using a file? to pick one.
  • You get every app and service holding it open: its name, process, PID and kind (app, service, Explorer, console). Details opens that process's card.
  • Folders are checked file by file, up to 2,000 files.
  • If nothing holds it, the card says so and suggests what else might be blocking you.

It uses the Windows Restart Manager, the same API installers and PowerToys File Locksmith rely on.

v0.3.5

November 8, 2026

Process tree

Switch the table from List to Tree to see which process started which.

  • Each process sits under its parent: apps under Explorer, browser helpers under the browser, services under their host.
  • Click the chevron to fold or unfold a branch.
  • Siblings follow the column you sort by, so the busiest child is still on top.
  • While you search, matches show together with their parents, even inside a folded branch, so you keep the context.

Windows reuses process IDs, which can make an unrelated process look like a parent. WinKillSwitch only counts a parent that is still running and started before its child, the same rule Process Explorer uses.

Your choice of list or tree is remembered.

v0.3.4

November 8, 2026

Quick palette

Press Ctrl+K inside WinKillSwitch, or Ctrl+Shift+K from anywhere in Windows, and start typing.

  • Processes: type part of a name or description. Each app shows once, with how many copies run and how much memory they use. Enter selects it and opens its details.
  • Groups: jump straight to one.
  • Commands: Clean memory, Analyze disk, Go to a tab, New group, Light, Dark or System mode, any of the six palettes, and Restart as administrator.

Arrow keys move, Enter runs, Escape closes. With nothing typed, the most useful commands are listed.

Ctrl+Shift+K works even when WinKillSwitch is behind other windows: it comes forward with the palette open. You can turn it off under Settings > Shortcuts, which also tells you if another app already uses that shortcut.

Find by window

Find a process by its window

Not sure which process owns a window? Press the target next to the search box and drag it onto the window.

  • While you drag, a label names the process and window under the pointer.
  • Let go, and that process is selected in the table and scrolled into view. If a search was hiding it, the search is cleared.
  • Press Details right after to see what it is and whether it can be managed.

Because you drag rather than click, the window you point at does not receive a click.

columns and GPU

Choose your columns

Right click the process table's header to pick what it shows. Besides name, PID, CPU and memory you can add:

  • Disk: read and write rate per process.
  • GPU and GPU engine: how much of the graphics card a process uses, and on which engine (3D, video decode, copy). It reads the same GPU Engine counters as Task Manager.

Your choice is saved. Reset to default brings back name, PID, CPU, memory, disk and GPU. Every column sorts when you click its header.

v0.3.1

November 8, 2026

About this process

Double click any process (or select it and press Details) to open a card that answers three questions.

What is it? About 40 common Windows processes, such as svchost, dwm, csrss, RuntimeBroker and MsMpEng, get a plain language explanation and a note on whether ending them is safe. Everything else shows its publisher and where it is installed.

Can WinKillSwitch manage it, and if not, why? The card says so in one line and explains the reason:

  • a critical system process Windows needs to run;
  • a protected process that Windows keeps every app away from, administrator or not (security software, DRM);
  • a process running as SYSTEM, a service account or administrator, with a one click Restart as admin when that would help.

What are the facts? The digital signature is verified, and you see who it runs as, when it started, its parent (click it to open the parent's card), its children grouped by name, its location and its full command line, each with a copy button. Open file location and Search the web are one click away.

v0.3.0

November 8, 2026

Disk cleaner

The Clean tab now has a Storage card next to the memory cleaner.

1. Press Analyze. WinKillSwitch looks through the places Windows and apps leave regenerable files, with a live count as it goes.

2. Review the list. Safe categories start ticked. The Recycle Bin and GPU shader caches start unticked, because emptying the bin is permanent and games rebuild shaders slowly. A browser's cache is skipped while that browser is open, and categories that need administrator rights say so.

3. Press Clean. You see how much space came back, how many files were removed, and how many were skipped because something was using them.

What it looks at: temporary files, Windows temporary files, crash dumps and error reports, the thumbnail cache, Chrome, Edge, Brave, Vivaldi and Firefox caches, DirectX, NVIDIA and AMD shader caches, Windows Update and Delivery Optimization downloads, and the Recycle Bin.

How it stays safe

  • It only removes files inside those fixed folders, found through Windows' own environment variables, and never the folders themselves.
  • It never follows a symbolic link or junction, so nothing outside those folders can be reached.
  • Temporary files changed in the last 7 days are kept, the same rule Windows Disk Cleanup uses.
  • Files in use are skipped and counted, never forced.

Fast: a temp folder with about 370,000 files scans in roughly 20 seconds.

v0.2.0

November 8, 2026

Memory cleaner

The new Clean tab shows your memory as a ring: in use, cached and free, with a two minute history underneath.

Press Clean memory and WinKillSwitch:

  • trims every app's working set, so pages they are not using go back to Windows;
  • as administrator, writes changed pages to disk and clears the standby cache.

Nothing is closed. While it runs, the button says which step it is on. When it finishes, the freed amount counts up and the cached slice of the ring shrinks. On a 16 GB test machine a clean freed 2.4 GB of free memory in about three seconds.

Windows refills memory as apps need it, so the gain is temporary by design. It helps most right before starting something heavy, like a game or a render.

Also

  • Cached memory is drawn in the palette's second accent so it reads apart from memory in use.
  • The history sparkline scales to its own range, so small changes are visible.

v0.1.0

November 8, 2026

The first public alpha of WinKillSwitch: a native Windows process manager drawn on the GPU with Rust and Rune.

Added

  • Live process table refreshed every 1.5 seconds with name, PID, CPU and memory, plus search by name, PID or path.
  • Process groups: create, rename in place, delete, add the selected rows, and see which members are running.
  • Glass interface: liquid, fluted and frosted glass over a live palette gradient, with a floating glass tab bar.
  • Six palettes with official light and dark variants, an accent picker, glass style and strength, and an animated background you can turn off.
  • Responsive under load: sampling runs on a background thread at lower priority, the interface above normal priority.
  • Safety sheets that list every process before any destructive action, and a one click relaunch as administrator.
  • --version flag and a headless --scene demo --snap out.png render for scripts and agents.

Known limitations

  • Ending processes and PauseSwitch's system changes are wired into the interface but not implemented yet; the app says so when you use them.
  • The executable is not code signed, so SmartScreen may warn on first launch. Choose More info, then Run anyway.
