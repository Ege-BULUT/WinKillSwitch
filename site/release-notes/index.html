v0.1.0

First releaseNovember 8, 2026

The first public alpha: the glass interface, live monitoring, groups and themes.

Added

  • Live process table refreshed every 1.5 seconds with name, PID, CPU and memory, plus search by name, PID or path.
  • Process groups: create, rename in place, delete, add the selected rows, and see which members are running.
  • Glass interface drawn on the GPU with Rune and rune-fx: liquid, fluted and frosted glass over a live palette gradient, with a floating glass tab bar.
  • Six palettes with official light and dark variants (Rune Aurora, Catppuccin, Rosé Pine, Tokyo Night, Kanagawa, Everforest), an accent picker, glass style and strength, and an animated background you can turn off.
  • Responsive under load: sampling runs on a background thread at lower priority while the interface runs above normal priority.
  • Safety sheets that list every process before any destructive action, and a one click relaunch as administrator.
  • --version flag and a headless --scene demo --snap render for scripts and agents.

Known limitations

  • Ending processes and PauseSwitch's system changes are wired into the interface but not implemented yet; the app says so when you use them.
  • The executable is not code signed, so SmartScreen may warn on first launch.
